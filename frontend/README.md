#  Sistema Web de Agendamiento - Clínica Dental

Este proyecto es una aplicación web completa diseñada para optimizar y automatizar la gestión de citas en una clínica odontológica. Permite a los pacientes agendar turnos de forma eficiente y ayuda al personal administrativo a mantener un control organizado de la agenda médica.

##  Tecnologías y Herramientas Utilizadas
* **Frontend & Backend**: Desarrollado e iterado utilizando metodologías de desarrollo acelerado con **Bolt** y asistencia de Inteligencia Artificial para la optimización de código.
* **Base de Datos**: Estructurada mediante **SQL** para garantizar la persistencia de datos, integridad referencial e historial de citas de los usuarios.
* **Control de Versiones**: Administrado con Git y GitHub, implementando buenas prácticas de seguridad mediante el uso de `.gitignore` para resguardar variables de entorno (`.env`).

##  Características Principales
*  Registro y agendamiento de citas en tiempo real.
*  Gestión de perfiles de pacientes y disponibilidad de horarios médicos.
*  Conexión y almacenamiento seguro en base de datos relacional.

##  Instalación y Configuración
1. Clona este repositorio.
2. Crea tu archivo `.env` en la raíz del proyecto basándote en las variables de configuración de tu entorno local.
3. Ejecuta el script de la base de datos SQL provisto.
4. Inicia el servidor de desarrollo.
